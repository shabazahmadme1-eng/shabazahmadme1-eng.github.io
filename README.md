# shabazahmadme1-eng.github.io

Portfolio of Shabaz Ahmad Hasib — machine learning engineer. Live at
**https://shabazahmadme1-eng.github.io/**

Hand-built with React, Vite and canvas; no template or UI kit. Every number on
the page comes from the underlying project repos.

```bash
npm install
npm run dev        # local dev server
npm run build      # production build into dist/
```

Pushing to `main` builds the site and deploys it to GitHub Pages
(`.github/workflows/deploy.yml`).
